About HealthPredict

Patient Health Outcome Predictor

Project Overview

HealthPredict is a healthcare analytics project that uses machine learning to predict whether a patient may be readmitted to a hospital within 30 days.

The system uses patient demographic information, hospital admission details, treatment information and selected medical-history features to generate a model-based prediction.

Dataset

The project uses the Diabetes 130-US Hospitals dataset containing patient records collected from hospitals in the United States between 1999 and 2008.

The dataset contains 101,766 patient records and is used to build a binary classification model for early readmission.

System Workflow

1

Patient Input

2

The input is converted into the format required by the trained model.

3

4

Result

The system displays the predicted outcome and estimated probability.

Important Notice

This project is intended for educational and analytical purposes only. The prediction generated by this system should not be considered a medical diagnosis or a substitute for professional medical advice.
